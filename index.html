Szybki start

Od pobrania do rozgrywki.

Wykonaj te trzy kroki, aby dodać VEX CLIENT do swojej instalacji Minecraft Java.

Przygotuj Fabric

Zainstaluj Fabric Loader dla Minecraft Java 1.21.4. Upewnij się, że masz również odpowiednią wersję Fabric API.

Włóż plik do mods

Przenieś pobrany plik do folderu .minecraft/mods, a następnie uruchom profil Fabric dla wersji 1.21.4.

FAQ

Masz pytanie?

Najważniejsze informacje przed instalacją.

Do jakiej wersji Minecrafta jest VEX CLIENT?

Do Minecraft Java Edition 1.21.4. Plik zawiera metadane moda deklarujące zależność od tej wersji Minecrafta.

Czy potrzebuję Fabric?

Tak. Mod wymaga Fabric Loader w wersji co najmniej 0.16.10 oraz Fabric API. Sam plik JAR nie zastępuje loadera ani API.

Gdzie wrzucić pobrany plik?

Do folderu .minecraft/mods. Jeśli folder nie istnieje, najpierw uruchom profil Fabric przynajmniej raz, a potem sprawdź katalog gry.

Co zrobić, gdy mod nie pojawia się w grze?

Sprawdź, czy uruchamiasz profil Fabric dla wersji 1.21.4, a w folderze mods znajdują się zarówno plik VEX CLIENT, jak i wymagane Fabric API.
